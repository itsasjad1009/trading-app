# Architecture

Aster Exchange is a Laravel 12 modular monolith. React/TypeScript pages use Inertia 2, Vite, Tailwind 4, Lucide, Radix accessible dialogs, and Lightweight Charts 5. Filament 4 provides staff authentication, dashboard, and an Operations Center. Fortify handles login, registration, password recovery, email verification and authenticator MFA. No separate Node server or Docker is used.

Domain services: Money parses decimal strings to integer cents; Ledger posts balanced entries; DemoMarket produces deterministic user-independent prices; TradingEngine accepts/reserves/settles orders; Operations reviews requests and audits decisions. Controllers validate inputs and scope reads to authenticated users. Models expose domain relationships. Database jobs queue broadcasts; Reverb publishes account refresh notifications to private channels. Without Reverb, the UI refreshes at 15-second intervals and charts at 10-second intervals. Countdown renders locally every second but never settles trades.

All money paths acquire the user row lock before posting. Settlement acquires user then trade locks. Consistent lock order and retryable transactions prevent double spending on MySQL-compatible transactional engines. SQLite is used only for isolated automated tests; it does not demonstrate MySQL concurrency behavior.

Core domain tables have foreign keys and idempotency uniqueness. Market candles are generated by the stateless demo adapter rather than persisted. Duration rules currently live in config/trading.php. No external feed or financial custody integration is implemented.

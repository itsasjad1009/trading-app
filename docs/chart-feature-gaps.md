# Chart features

Implemented using Lightweight Charts: area and candlestick series, volume histogram, crosshair, zoom/pan, price/time axes, responsive resizing, pair selection, server-generated history, six timeframes persisted locally, data loading/disconnection status.

Not implemented: arbitrary drawings, indicator marketplace, custom studies, rich TradingView toolbar, alerts, saved drawings, full licensed Charting Library. The screenshot's toolbar is not reproduced with inert controls. Advanced drawings/indicators require additional original engineering or an appropriately licensed charting product. Simulated data is explicitly labeled and generated on the server.
